# Oudere sessies importeren

Open een `.ses`-bestand via **File → Open Session**. SoundSausage ondersteunt
een beperkte oudere sessie-indeling met 16-bit WAV-bronnen, eenvoudige clips,
spoor-/clipvolume en pan. Bronbestanden blijven ongewijzigd. Als WAV-bestanden
ontbreken, kan een andere bronmap worden gekozen.

Niet-ondersteunde automation, cues of sessievarianten worden gemeld. De import
is nog geen algemene, verliesvrije conversie van alle oudere sessies.

Sla het resultaat op als een SoundSausage-project (`.celp`). Daarin wordt de
gebruikte audio ingebed. Opslaan als `.ses` wordt niet ondersteund.
